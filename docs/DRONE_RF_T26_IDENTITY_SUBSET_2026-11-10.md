## 1. Finding that changes T09

A spectral-only identity model on this subset **has already been trained and evaluated on held-out physical units** (`docs/DRONE_ML_EXPANDED_FINAL_VALIDATION.md`, 22 October). On the Air 2 / Air 2S / Mini 4 Pro calibration units it reached 68–72% window accuracy and 78–83% recording-vote accuracy, with one Air 2S unit at 0/36 windows.

Those three models are advertised as three different link families, so that result is a cross-family result, and it is already weak. T09 should therefore not repeat the same run. It should (a) reuse those checkpoints and tensors as the cross-family baseline, (b) add the same-family section below, and (c) investigate the Air 2S unit-4 failure, which is the most informative existing evidence about unit-versus-model learning.

## 3. Same-family pair search

Requirement: two different models on one verified link family, each with independent physical units in training and evaluation, ideally on the same receiver and band.

| Candidate pair | Family | Verdict | Reason |
|---|---|---|---|
| Air 2S vs Mini 3 Pro (DRFF-R2) | O3 | **Only viable pair; needs a decision** | Same receiver, band and dataset. Air 2S has 7 units; Mini 3 Pro has 2. But Mini 3 Pro is the project's only unknown-development model, and the plan forbids repurposing held-out unknown models. |
| Mini 4 Pro vs Mini 5 Pro (DRFF-R2) | O4 / O4+ | Not usable | Mini 5 Pro has one unit; O4+ may not be the same waveform as O4. |
| Air 2S vs Mavic 3 (DRFF-R2) | O3 / O3+ | Not usable | Mavic 3 has one unit. |
| Mavic 3 vs mavic3C / mavic3S (DRFF-R2) | O3+ | Not usable | One unit each; the latter two are locked final-test units. |
| Inspire 2 vs Phantom 4 (Tampere + DroneDetect V2) | Lightbridge | Possible later, weak | Both models appear in both datasets, so one can train on one receiver and test on the other. One unit and about one second per class in Tampere; DroneDetect is not yet format-verified (T02). |
| Air 2 vs Mini 2 vs RFUAV Mini 3 | OcuSync 2.0 | Not usable | Each model comes from a different dataset, so model is fully confounded with receiver. |
| Mini 4 Pro vs Avata 2 (DRFF-R2 + RFUAV) | O4 | Not usable | Same confound; Avata 2 is one unresolved unit. |

**Result: the admitted public data contains no same-family pair that satisfies the plan as written.** One pair (Air 2S vs Mini 3 Pro) satisfies it only if the Mini 3 Pro role is changed.

## 4. Decision needed (Sudeep)

**Option A — use Mini 3 Pro in a separate, versioned pairwise diagnostic.**
Train Air 2S units 1–2 and Mini 3 Pro unit 2; evaluate Air 2S units 3–4 and Mini 3 Pro unit 1 (receiver `u2` on both sides). Mini 3 Pro stays the unknown model in the main experiment; the diagnostic is a separate split that never feeds the main model. Cost: Mini 3 Pro unit 1 has only 12 files, both units were already inspected, and this is one pair on one receiver. It answers the central question now, with existing data.

**Option B — keep Mini 3 Pro untouched and report the gap.**
T09 reports "same-family separability untested" and T32 stays open until new data exists. That means recording or obtaining a second model on a shared link with at least two physical units per model.

Recommendation: Option A, labelled as a diagnostic. It is the only way to learn anything about within-family separability before new recordings, and it does not weaken the main experiment's unknown-model evaluation.

    Evidence order

    Each row gets one answer to "which model is it?". The strongest evidence present decides the tier.

    1. ConfirmedA readable DJI DroneID packet names the model. Self-reported, not authenticated.
    2. LikelyDroneID is present but encrypted. Only models seen to encrypt it, whose link shows the row's timing group, remain.
    3. FamilyOnly the video link was seen. Its timing group gives the family and the models measured in it; the classifier's models may be listed inside it.
    4. ReportedOnly a Remote ID broadcast: an ID and aircraft type, no model.
    5. UnknownDroneID was read, but its product code is not in the table.
    6. ClassifierOnly the universal classifier saw it. Weakest tier, lowest alert severity, off by default.
